# Casa en orden

Aplicación para gestionar el inventario completo del hogar:
saber qué productos y objetos tienes, en qué cantidad y dónde
están guardados, además de identificar qué necesitas comprar.

## Objetivo del proyecto

Aprender a desarrollar y desplegar una aplicación completa:
frontend, API, base de datos, persistencia, autenticación y pruebas.

## Funcionalidades previstas

- Registro e inicio de sesión.
- Gestión de hogares y ubicaciones.
- Inventario de productos y cantidades.
- Registro de compras y consumos.
- Control de existencias mínimas.
- Lista de compra.

## Tecnologías previstas

- Frontend: Angular y TypeScript.
- Backend: Java y Spring Boot.
- Base de datos: PostgreSQL.
- Persistencia: Spring Data JPA / Hibernate.
